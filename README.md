# NightShift AI

> AI agents that never clock out.
>
> **[▶ Visit the website](https://aziz4rehman-hue.github.io/nightshift-ai/)**

The website for NightShift AI, which builds AI receptionists and booking agents for salons, clinics,
gyms and other appointment-based local businesses.

- Night theme: live star sky with shooting stars and cursor constellations, a scroll clock that runs 9 PM → 7 AM with a dawn glow, missed calls that flip into bookings, an AI voice orb, card spotlights and a 3D call card
- Animated example call in the hero
- Agents, how it works, industries, pricing plans, FAQ
- A demo-request form that opens WhatsApp or email with the enquiry already written
- Live product demo: [ChairLine](https://aziz4rehman-hue.github.io/chairline/)

Plain HTML, CSS and JavaScript. No build step. Contact details are set at the top of `main.js`.
